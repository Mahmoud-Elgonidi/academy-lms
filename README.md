# Academy LMS

منصة SaaS لأكاديميات التعليم الأونلاين اللي بتدّي حصص فردية مباشرة (1:1) في القرآن واللغة العربية واللغات والمواد الدراسية. المنصة بتخدم أكتر من أكاديمية، وكل أكاديمية بتدير مدرسيها وشفتاتهم، وطلابها وأولياء أمورهم، والباقات والدفع، والحصص المباشرة، والمنهج والتقييم.

> **الحالة:** التنفيذ شغال. فيه دلوقتي أساس الـ backend (تعدد الأكاديميات بـ RLS، والمستخدمين، وتسجيل الدخول، والتوقيت المحلي)، ولوحة الإدارة: **لوحة العمليات اللحظية** بشكلين، و**ابحث عن مدرس** (توافر حقيقي بالأسابيع وحجز مبدئي 10 دقايق)، و**تسجيل الطالب على باقة** (فاتورة، ومواعيد أسبوعية، وحصص بتتولّد لقدام)، و**الفواتير والدفع اليدوي** (الدفع بيضيف رصيد البلوك ويأكّد الحصص بالترتيب)، و**رصيد بالدقيقة** في دفتر مايتعدلش (خصم الحصة، ورصيد تعويض لو المدرس غاب، وفاتورة التجديد بتطلع لوحدها)، و**سياسة الإلغاء والتعويض** (مين طلب وقبلها بكام ساعة بيحددوا مصير الرصيد وأجر المدرس، بإصدارات، والحصة المش مدفوعة بتتلغي لوحدها قبلها بيوم)، و**حساب الطالب** (إلغاء وتأجيل بالسياسة، وحجز حصة تعويض، وتغيير المدرس)، و**المناهج** (برنامج ← مستويات ← وحدات ← دروس، بإصدار منشور)، و**تقرير بعد كل حصة** بيبدأ من خطة اليوم ويحرّك تقدم الطالب على الـ roadmap (النسبة، وهو فين، والوقت المتوقع للإنهاء)، و**الواجبات** (نص أو ملف أو تسجيل صوتي)، و**منطقة المدرس** على `/teach`، و**الباقات والأسعار** لكل منطقة، و**مقترحات الشفتات** (المدرس يقترح، والإدارة تراجع الأثر وتعتمد أو تطلب تعديل أو تعمل عرض مضاد)، و**الهوية والألوان** بقوالب، و**إعداداتي**. التفاصيل في [apps/api/README.md](apps/api/README.md).

## جرّبه على جهازك

محتاج بس [Docker Desktop](https://www.docker.com/products/docker-desktop/):

```sh
git clone https://github.com/Mahmoud-Elgonidi/academy-lms.git
cd academy-lms
docker compose up
```

أول مرة بتاخد كام دقيقة (بتنزّل المكتبات وتجهّز قاعدة البيانات). لما تظهر رسالة `Server running`، افتح:

- **http://localhost:8000/admin**
- الدخول: `owner@demo.test` / `password`

البيانات التجريبية فيها مساء كامل من الحصص حوالين وقت التشغيل: مدرس متأخر، وطالب ما دخلش، واتصال ضعيف، وحصة مش مدفوعة، وحصص ماشية وجاية. وفيها 6 باقات بأسعار 6 مناطق، و8 طلاب مسجلين بفواتير في كل الحالات (مدفوعة، ومدفوع جزء، ومستحقة، ومتأخرة). زياد بدأ من 26 يوم: 6 حصص اتخصمت، وحصة المدرس غاب فيها بقت رصيد تعويض، وفاتورة التجديد طلعت لوحدها. ومريم لغت حصة في ميعاد (الرصيد رجع)، وآدم لغى متأخر (الحصة ضاعت وأجر المدرس النص)، وليان أجّلت أول حصة ساعة. وفيها 3 مناهج منشورة ومسودة، وتقارير حصص زياد (واحد متأخر، وواحد اتراجع، وآخر حصة لسه تقريرها مطلوب)، وواجبات في كل الحالات منها تسجيل صوتي. عشان تبدأ من جديد بمواعيد جديدة: `docker compose exec api composer demo`.

المحاسب: `accountant@demo.test` / `password` (الفواتير والأسعار، من غير الجداول).

منطقة المدرس: **http://localhost:8000/teach** بـ `khaled@demo.test` / `password` (مدرس زياد): تقاريره، والتقرير المتأخر بخطة اليوم جاهزة، والواجب الصوتي اللي مستني تصحيح.

### لما تسحب تحديث جديد

```sh
git pull
docker compose up
```

مش محتاج حاجة تانية. الـ container لوحده بيثبّت المكتبات الجديدة لو `composer.lock` اتغير، وبيشغّل الـ migrations الجديدة، وبيبني البيانات التجريبية من جديد لو شكلها اتغير. محتاج `docker compose up --build` بس لو الـ `Dockerfile` نفسه اتغير.

## التقنيات

| الجزء | التقنية |
|---|---|
| Backend + لوحات الإدارة | Laravel (Modular Monolith) + Filament |
| قاعدة البيانات | PostgreSQL مع Row-Level Security |
| Queues وCache وRealtime | Redis، وHorizon، وReverb |
| تطبيقات الموبايل | Flutter: تطبيق واحد للطالب وولي الأمر والمدرس |
| الويب | Next.js: البوابة، والفصل المباشر، والمواقع العامة |
| الفيديو | LiveKit |

## التشغيل السريع

```sh
docker compose up -d          # Postgres (بالأدوار التلاتة) + Redis + Mailpit
cd apps/api
composer install && cp .env.example .env && php artisan key:generate
composer migrate && php artisan db:seed
composer test
```
