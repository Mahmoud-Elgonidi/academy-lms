# العربية في المنصة

كل ما يقرؤه الناس بالعربية مكتوب بالفصحى المعاصرة: اللوحات والكونسول والبوابة والتطبيق، والإشعارات والرسائل والبريد، وصفحة المنصة وصفحات الأكاديميات، والخصوصية والشروط، وبيانات العرض التجريبي. تبقى بالعامية المصرية سطور `voice:` في فيديوهات الدورة (`tools/course`) وحدها.

## الأسلوب

- فصحى واضحة قصيرة بلغة التطبيقات: «ادخل»، «أرسل الرمز»، «لا توجد حصص اليوم»، «حدث خطأ. حاول مرة أخرى.»
- لا تكلّف ولا سجع. والتشكيل فقط حيث قد تُقرأ الكلمة خطأً (المعلّم، تُلغى).
- المخاطبة بالمفرد المذكر كما هي، والأزرار بفعل الأمر («احفظ»، «ألغِ الحصة»).
- الأرقام كما هي في النص، وصيغ الجمع العربية كاملة: «حصة واحدة، حصتان، 3 حصص، 11 حصة».
- المتغيّرات (`:name`، `{count}`، `{n, plural, …}`) لا تتغيّر أبدًا، ولا المفاتيح ولا الإنجليزية.

## شكل الأطفال

فصحى مبسّطة: جمل قصيرة جدًا وكلمات يعرفها طفل في السابعة («تحدّث مع معلّمك»، «أحسنت! ربحت نجمة»). الرموز التعبيرية تبقى في كلام الأطفال وحده.

## كلمة واحدة لكل شيء

| نقول | لا نقول |
|---|---|
| المعلّم | المدرّس، المدرس |
| المزيد (آخر تبويب) | القايمة |
| القائمة (اسم قائمة التنقل لقارئ الشاشة) | القايمة |
| المساعدة (الدعم والمساعدة معًا) | الدعم |
| المدفوعات | الفلوس |
| الرمز (رمز الدخول) | الكود |
| الحصة (درس مباشر)، الدرس (من المنهج)، المحطة (الدرس في الرحلة) | |
| ولي الأمر | |
| الملصقات، كائناتي | الستيكرز |

## ما يرفضه الفحص

كلمات العامية هذه، كلمةً مستقلة، في أي نص عربي: ده، دي، دول، مش، مفيش، عشان، علشان، إزاي، ازاي، إيه، ايه، فين، ليه، دلوقتي، كده، بتاع، بتاعة، بتاعك، اللي، عايز، عاوز، يلا، لسه، بقى، أوي، تاني، كمان، بس، خلّي، خلي، قايمة، دقايق، إمتى، امتى. ومعها كلمات الجدول السابق. القائمة واحدة في الأسطح الثلاثة:

- الـ API: `tests/Arch/ArabicWordingTest.php` على كل `lang/ar`.
- البوابة: `src/lib/messages.test.ts` على `messages/ar.json`.
- التطبيق: `tool/strings.py` عند كتابة ملفات الـ ARB.
